# Intel MacBook Pro 11–16 hardware inventory

Northwood recognizes the following SMBIOS system products when the system
vendor is `Apple Inc.`. The EFI log reports `HOST APPLE model=… expected_bridge=…`
and the host inventory includes the model in `SystemModel` and the expected
coprocessor in `AppleExpectedBridge`. This classification records the factory
configuration. Driver selection still relies on observed devices and their
individual admission checks.

| Models | Expected bridge | Factory graphics families to validate |
| --- | --- | --- |
| `MacBookPro11,1`, `MacBookPro11,2`, `MacBookPro11,4` | None | Intel Haswell |
| `MacBookPro11,3` | None | Intel Haswell and NVIDIA Kepler |
| `MacBookPro11,5` | None | Intel Haswell and AMD GCN |
| `MacBookPro12,1` | None | Intel Broadwell |
| `MacBookPro13,1` | None | Intel Skylake |
| `MacBookPro13,2` | T1 | Intel Skylake |
| `MacBookPro13,3` | T1 | Intel Skylake and AMD Polaris |
| `MacBookPro14,1` | None | Intel Kaby Lake |
| `MacBookPro14,2` | T1 | Intel Kaby Lake |
| `MacBookPro14,3` | T1 | Intel Kaby Lake and AMD Polaris |
| `MacBookPro15,1`, `MacBookPro15,3` | T2 | Intel Coffee Lake and AMD Polaris or Vega, depending on configuration |
| `MacBookPro15,2`, `MacBookPro15,4`, `MacBookPro16,3` | T2 | Intel Coffee Lake |
| `MacBookPro16,1`, `MacBookPro16,4` | T2 | Intel Coffee Lake and AMD Navi (RDNA) |
| `MacBookPro16,2` | T2 | Intel Ice Lake |

## Device validation

The model entries above have host-side classification tests. The Northwood
hardware checks below still need on-device results. Record the exact
EFI build, model identifier and device identifiers with each result.

| Area | Evidence needed to declare support |
| --- | --- |
| USB installation | Boot the installation media on the Mac, reach the installer, then complete installation and reboot from the target. Verify boot picker navigation with the built-in and an external keyboard. |
| T2 internal SSD | Identify the Apple storage controller and its namespaces after `ExitBootServices`. On a backed-up test system, install to a dedicated target and verify persisted writes and a cold reboot from internal storage. |
| T1 and T2 Touch Bar | Identify the bridge generation and resolve its HID/display transport. Verify function keys, display behavior and sleep and wake on each bridge generation. |
| Keyboard and trackpad | Identify the device's USB, SPI, I2C or bridge transport. Verify key and modifier events, trackpad motion, scrolling and clicks through the installer and guest, and test suspend and resume. |
| Wi-Fi and Bluetooth | Identify the exact Broadcom functions, board configuration and firmware. Test Wi-Fi association and data transfer, Bluetooth pairing and input, and coexistence under traffic. |
| AirDrop | Verify discovery and file transfer in both directions with a second supported Apple device. A Wi-Fi link or a Bluetooth controller attachment covers only part of this path. |
| GPU and built-in display | Validate panel output, brightness, hotplug, sleep and wake, and guest Metal workloads. For dual-GPU models, test each GPU and the switching path. Terascale requires a separate device fixture outside the factory GPUs in this list. |
| Other built-in devices | Validate speakers, microphones, webcam, battery, lid, fans, sensors, SD reader, Thunderbolt, sleep and wake on configurations that have them. |

The Northwood catalog records existing driver registrations, including generic
NVMe and BCM4377 Bluetooth. The Apple SPI input driver and the T2 buffer-copy
engine and virtual USB host controller are Linux references for the respective
transports. [Northwood driver catalog](../DRIVERS.md)
